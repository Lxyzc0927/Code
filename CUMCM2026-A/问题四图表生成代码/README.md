# 问题四五张论文图生成代码

本目录用于生成问题四所需的五张论文图：

- 图7-1 烘干时间网格收敛曲线
- 图7-2 药材半径随时间变化
- 图7-3 不同时刻水分浓度径向分布
- 半径插值方法比较.png（图7-4）
- 烘干时间对比.png（图7-5）

## 使用方法

在本目录执行：

```bash
python 生成问题四五张图.py
```

程序从 `data/plot_data.npz` 读取数据，并将 PNG 输出到 `figures/`。运行环境需要 Python 3、NumPy、SciPy、Matplotlib。

图7-1、图7-5使用《问题四(3).txt》中的论文表7-1和表7-5数值，图7-3使用表7-2给出的剖面数据，图7-2与图7-4使用附件2半径观测数据。
